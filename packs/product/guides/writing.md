# Writing Guidelines

## The Fundamental Constraint

> Write for someone who scans in 3 minutes, not for someone who reads linearly.

If your document needs to be read cover-to-cover to understand the point, the problem isn't length. It's visual density.

---

## Writing Principles

### 1. Write for scanning

People scan before they read.

Good:

```
Platform stops issuing VAT invoices.

Instead it generates:

- Monthly Report
- Accounting Note
```

Bad:

```
The platform will cease issuing VAT invoices in accordance with the new fiscal regime applicable from August 1st, 2026.
```

### 2. One idea per paragraph

Maximum 3-4 lines. If you need more, it's two ideas. Split them.

### 3. Prefer nouns over verbs

❌ `The platform performs generation of the monthly report...`
✅ `Monthly Report generation`

### 4. Prefer active voice

❌ `The report is generated by the system...`
✅ `The system generates the report.`

### 5. Explain the why once

Don't repeat context in every FR. State it in Context, then reference it.
