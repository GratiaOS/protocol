# Archive

Explorations that didn't become the current protocol. Kept for
history, not in use.

- `v0.2.1-vocabulary/` — an earlier, more elaborate version of the
  three verbs (moods, contraindications, grammar rules, adapter
  types). Replaced by the single-file `protocol.json` after real use
  showed people choose the right verb themselves, without routing or
  interpretation logic.
- `v0.3.0-microkernel/` — a 6-week plan for a knowledge graph runtime
  (ISA opcodes, schema validation, components, monitors). Never
  implemented. Superseded by the same realization: the protocol only
  needs to be a handshake, not an engine.

Current source of truth: `/protocol.json` in repo root.
